# Meet the Builders — VLOG Script

Target length: 75–90 seconds

Replace `[CITY, COUNTRY]` and `[PROJECT LINK]` before recording.

## 0:00–0:10 — Face-camera introduction

**Visual:** Speak directly to the camera. Display your name and location.

**Narration:**

"Hi! I'm Piyush from [CITY, COUNTRY]. I built this project for the Google Cloud
Gen AI Academy APAC Edition on Hack2Skill, and I'm sharing it through Meet the
Builders."

## 0:10–0:22 — The problem

**Visual:** Show quick shots of separate task lists, notes, calendars, and
reports.

**Narration:**

"The problem I chose is fragmented productivity. Students, professionals, and
small teams switch between tools for tasks, notes, schedules, and progress.
That creates extra effort and makes important information easier to miss."

## 0:22–0:28 — Introduce the solution

**Visual:** Reveal the application title and open the assistant.

**Narration:**

"So, I built the Multi-Agent Productivity Assistant—one secure conversation
for managing everyday work."

## 0:28–0:50 — Solution overview

**Visual:** Stay on face camera or use polished, pre-recorded B-roll of the
application home screen and four capability cards. Do not type prompts or run a
live demonstration.

**Narration:**

"The assistant brings four capabilities together. It can organize tasks,
retrieve notes by meaning, manage calendar events, and turn activity into useful
productivity insights. Behind one simple conversation, a coordinator routes
each request to the right specialist."

## 0:50–1:10 — How it was built

**Visual:** Show the architecture diagram, then brief Google Cloud console
shots. Display the complete service list as on-screen text.

**Narration:**

"Gemini 2.5 Flash on Vertex AI and Google Agent Development Kit power the
experience. AlloyDB AI enables semantic search, BigQuery provides live
analytics, and Cloud Run hosts the solution. IAM, Secret Manager, and private
networking keep it secure."

**On-screen service strip:**

`Vertex AI • Google ADK • Cloud Run • AlloyDB AI • BigQuery • Secret Manager • Cloud IAM • Cloud Build • Artifact Registry • Cloud Logging • Cloud Monitoring`

## 1:10–1:25 — Face-camera impact and closing

**Visual:** Return to the camera. Finish on the project name, campaign name, and
project link.

**Narration:**

"This project helps people spend less time organizing and more time doing
meaningful work. It turned my Gen AI Academy learning into a working solution.
I'm proud to join Meet the Builders, and I invite APAC builders to share their
ideas too. Happy building!"

**End card:**

- `Multi-Agent Productivity Assistant`
- `Google Cloud Gen AI Academy APAC Edition`
- `Meet the Builders`
- `[PROJECT LINK]`

## Recording Notes

- Record the introduction and closing in a quiet, well-lit location.
- Look into the camera and speak conversationally instead of reading quickly.
- Use short, pre-recorded interface shots or still screenshots as B-roll; do not
  type prompts or depend on a live response during the VLOG.
- Use captions throughout and emphasize the problem, solution, and impact.
- Use only synthetic demo data; never show passwords, tokens, or secret values.
- Export at 1080p and make the framing safe for both landscape and LinkedIn crops.
